In 2003, a candidate in a Belgian election received 4,096 extra votes that no human being had cast. The votes appeared from nowhere. The best explanation anyone has is that a single particle from outer space struck a chip in a voting machine and flipped a single bit of memory from 0 to 1. One cosmic ray, one bit, 4,096 phantom votes. And the reason it was exactly 4,096 is a number you can now read like a fingerprint.

Start with the event. In the town of Schaerbeek, near Brussels, Belgium was using electronic voting machines. When the votes were tallied, officials spotted an impossibility: one candidate had received more votes than were even mathematically possible given the number of voters. Something had added votes that didn't exist. A manual recount found the correct total, and the discrepancy, the number of phantom votes, was exactly 4,096. Not around 4,000. Not 4,100. Precisely 4,096.

And that precise number is the whole clue, because 4,096 is not a random quantity. It's 2 to the power of 12, a perfect power of two, which is a deeply suspicious thing for an error to be. Here's why it points straight at the hardware. Computers store numbers in binary, as a row of bits, and each bit represents a specific power of two: the first bit is worth 1, the next 2, then 4, 8, 16, and so on, doubling each time. The 13th bit in that row is worth exactly 2 to the 12th, which is 4,096. So if one specific bit, the one in the 4,096 position, were to flip from 0 to 1, the stored number would jump up by exactly 4,096, instantly, with no other change. The oddly specific vote count is the signature of a single bit flipping in exactly one place. No software bug naturally produces a clean power of two like that; a flipped bit does, every time.

So what flipped it? Investigators couldn't prove it beyond doubt, but the most plausible explanation, and the one the case is famous for, is a cosmic ray. Space is full of high-energy particles, and when they hit our atmosphere they produce showers of secondary particles that rain down on us constantly, passing through buildings, through us, harmlessly, all day. But every so often, one of these particles strikes a transistor in a memory chip with just enough energy to knock it into the opposite state, flipping a stored bit. Engineers call this a single-event upset. The vast majority do nothing. But a chip has billions of bits, and the particles are relentless, so once in a great while, one lands in exactly the wrong place at exactly the wrong moment.

This is not folklore, and that's the part engineers need to take seriously. When Google studied the memory in its own vast data centers, it found that memory errors were far more common than people had assumed, with a meaningful fraction of memory modules experiencing errors over a year. Not all from cosmic rays, heat and age and manufacturing flaws contribute too, but the common thread is bits silently going wrong in memory that's supposed to be perfectly reliable. At the scale of thousands of machines with terabytes of memory, bit flips aren't a freak event, they're a steady statistical certainty, the same lesson as disk failures at scale.

Which is exactly why serious computers defend against it, with a technology called ECC memory, error-correcting code memory. Here's the mechanism. For every chunk of data it stores, say 64 bits, an ECC module stores a handful of extra bits, computed from the data using a scheme called a Hamming code. These extra bits are arranged so cleverly that if any single bit in the chunk flips, the pattern of the extra bits reveals not just that an error occurred, but exactly which bit went wrong, so the hardware flips it back on the spot, silently, before the bad value is ever used. If two bits flip at once, it can at least detect the problem and raise an alarm rather than hand over corrupt data. Your laptop and phone probably don't have ECC, it costs a little more. But the servers running banks, databases, and, one hopes, modern voting machines, do, precisely so that a particle from space can't change a number.

One particle from space. One bit flipped, in the position worth 4,096. And 4,096 votes that nobody cast, in a real election. The giveaway was the number itself, a clean power of two, the fingerprint of a single bit, and the reason the machines that matter now use memory that checks itself.
