Thirty-seven seconds after ignition, a rocket that cost seven billion dollars to build tore itself apart in the sky. The cause was a single number that didn't fit in a box, running in code that didn't even need to be there. This is Ariane 5, flight 501, and it's the most expensive integer overflow in history.

It's June 4th, 1996. The European Space Agency launches its new Ariane 5 rocket for the first time. About half a minute in, it suddenly swerves, the aerodynamic forces rip it apart, and it self-destructs. The rocket and its four satellites, worth around 500 million dollars, are gone in seconds.

Now the mechanism, because every layer here is a lesson. The rocket has an inertial reference system, the unit that senses which way it's pointing and how fast it's moving. Inside, a piece of code took a measurement of horizontal velocity, stored as a 64-bit floating point number, a format that can hold enormous values, and converted it into a 16-bit signed integer. A 16-bit signed integer can only hold values up to 32,767. The horizontal velocity of Ariane 5 produced a number bigger than 32,767. It didn't fit. The conversion overflowed, and that part of the system threw an error and shut down.

Here's the first twist. There were two of these units, a main and a backup, for safety. But they ran the identical software. So the backup hit the exact same oversized number a few milliseconds earlier and had already failed the same way. Redundancy only protects you from a part breaking. It does nothing against a bug, because the bug is in both copies. That's a point worth carrying into any design review: two of the same thing is not fault tolerance against a logic error.

Here's the deeper twist, the one that stings. That conversion was part of a routine that aligned the guidance system before launch. On the older Ariane 4 rocket, it kept running for a few seconds after liftoff, harmlessly. It served no purpose at all once Ariane 5 was flying. The engineers had reused proven Ariane 4 code to save effort, which is usually wise. But Ariane 5 flew faster and built up horizontal velocity far quicker than Ariane 4 ever did. So a value that was always small enough on the old rocket grew large enough on the new one to blow past 32,767. The code wasn't wrong for the rocket it was written for. It was wrong for the rocket it was pasted into.

And the last cut: when that unit failed, it didn't send a velocity. It sent its error status, a diagnostic pattern of bits, down the same channel. The main computer read that diagnostic pattern as if it were real flight data, interpreted it as a wild course deviation, and swung the engine nozzles hard over to correct for a problem that didn't exist. That violent correction is what tore the rocket apart.

So four things in a chain, each a lesson an engineer can name: a number that outgrew its type, redundancy that couldn't help because both copies shared the bug, reused code running in a context it was never tested in, and an error value treated as valid data. Any one of them caught, and the rocket flies.

Thirty-seven seconds. Five hundred million dollars. One conversion to a 16-bit integer that nobody needed to run.
